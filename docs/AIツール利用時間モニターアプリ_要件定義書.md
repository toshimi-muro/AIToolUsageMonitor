# 1. 概要

## 1.1 背景

生成AIの普及により、学習や開発においてAIツールを利用する機会が増加している。

一方で、AIに頼り過ぎることで自分で考える時間が減少する可能性があるため、AIツールの利用状況を把握できる仕組みが必要であると考えた。

## 1.2 目的

Windowsイベントログを利用してアプリケーションの利用時間を算出する仕組みを実装する。

主な対象はChatGPTやCopilotなどのAIツールとし、利用時間を可視化することで利用状況の把握や自己管理を支援する。

## 1.3 対象利用者

個人利用者

---

# 2. システム概要

システムに登録された対象アプリケーションについて、Windowsイベントログを利用して利用時間を算出し、結果を画面上で確認できるWindowsデスクトップアプリケーションを開発する。

主な対象としてChatGPTやCopilotなどのAIツールを想定する。

対象アプリケーション情報は設定ファイルで管理し、利用者は登録済みの対象アプリケーションから選択して利用する。

---

# 3. 機能要件

## 3.1 アプリ利用時間算出機能

利用者が選択した対象アプリケーションの利用時間を算出できること。

## 3.2 利用時間表示機能

算出した利用時間を画面上で確認できること。

## 3.3 利用制限支援機能

利用制限モードにおいて、利用時間が利用者が設定した閾値を超えた場合にメッセージを表示できること。

## 3.4 対象アプリ選択機能

利用者が登録済みの対象アプリケーションを選択できること。

## 3.5 利用モード選択機能

利用者が以下の利用モードを選択できること。

- 学習モード
- 利用制限モード

利用制限モードでは利用時間閾値を設定できること。

## 3.6 メッセージ表示機能

選択した利用モードに応じてメッセージを表示できること。

メッセージはシステム標準メッセージを使用する。

また必要に応じて利用者が指定したメッセージファイルを読み込み表示できること。

---

# 4. 非機能要件

## 4.1 動作環境

Windows 11 上で動作すること。

## 4.2 操作性

専門知識を必要とせず操作できること。

## 4.3 性能

日常利用に支障がない範囲で動作すること。

---

# 5. 前提条件

- Windowsイベントログが正常に記録されていること。
- 設定ファイルに対象アプリケーション情報が登録されていること。
- 対象アプリケーションに関するイベント情報がWindowsイベントログから取得可能であること。
- メッセージファイルを利用する場合は指定されたファイルが存在すること。

---

# 6. 制約事項

- 個人利用を想定する。
- ローカル環境で利用する。
- 対象アプリケーション情報は設定ファイルで管理する。
- 利用者による対象アプリケーション情報の登録・編集・削除は行わない。
- 利用者は登録済みの対象アプリケーションから選択して利用する。
- 利用時間はWindowsイベントログに記録された情報を基に算出する。
- Windowsイベントログに対象アプリケーションの情報が記録されていない場合は算出対象外とする。
- イベント情報の出力有無および内容は対象アプリケーションの仕様に依存する。
- 算出結果はWindowsイベントログから取得可能な情報を基に算出した結果であり、実際の利用時間との一致を保証しない。
- 利用制限モードは利用者への注意喚起を目的とし、アプリケーションの利用を強制的に制限するものではない。

---

# 7. 対象外（スコープ外）

以下の機能は本システムの対象外とする。

- AI利用内容の解析
- AI利用時間の厳密な判定
- 長期間の統計分析
- 月次・年次集計
- クラウド連携
- 複数ユーザー管理
- AI依存度の算出
- Webページ単位の利用判定
- 常駐監視によるリアルタイム算出
- 画面認識（OCR）による利用判定
- 利用者による対象アプリケーション情報の登録・編集・削除機能
- アプリケーションの強制終了
- アプリケーション起動制御
- OSロック等の強制的な利用制限

※ 上記の一部機能については、将来的な拡張機能として検討する可能性がある。

---

# 8. 利用モード

## 8.1 学習モード

利用時間を確認しながら学習を支援するモード。

設定されたメッセージファイルが存在する場合はその内容を表示し、存在しない場合はシステム標準メッセージを表示する。

## 8.2 利用制限モード

利用者が設定した利用時間閾値を用いて利用状況を確認するモード。

利用時間が閾値以上である場合は警告メッセージを表示する。

閾値は画面上から設定できるものとする。

設定されたメッセージファイルが存在する場合はその内容を表示し、存在しない場合はシステム標準メッセージを表示する。
