# 1. システム概要

## 1.1 システム名称

AIツール利用時間モニターアプリ

## 1.2 システム概要

本システムは、Windowsイベントログを利用して対象アプリケーションの利用時間を算出し、利用状況を画面上に表示するWindowsデスクトップアプリケーションである。

主な対象アプリケーションはChatGPTおよびCopilotとする。

## 1.3 開発目的

Windowsイベントログを利用してアプリケーション利用時間を算出する仕組みを実装することを目的とする。

# 4. 機能設計

## F01 設定ファイル読込

### 概要

設定ファイルから対象アプリケーション情報を取得する。

### 入力

- config.json

### 出力

- 対象アプリ一覧

---

## F02 イベントログ取得

### 概要

指定期間内のWindowsイベントログを取得する。

### 入力

- 対象アプリ
- 開始日時
- 終了日時

### 出力

- イベント一覧

---

## F03 利用時間算出

### 概要

開始イベントおよび終了イベントを利用して利用時間を算出する。

### 入力

- イベント一覧

### 出力

- 利用時間

---

## F04 利用状況判定

### 概要

利用時間と利用時間閾値を比較する。

### 判定条件

```text
利用時間 < 閾値
```

または

```text
利用時間 >= 閾値
```

---

## F05 メッセージ取得

### 概要

利用モードおよび利用状況判定結果に応じて表示メッセージを取得する。

### 学習モード

| 条件 | 表示内容 |
|--------|--------|
| 閾値未満 | LearningMessage.txt |
| 閾値以上 | 設定目標達成です |

### 利用制限モード

| 条件 | 表示内容 |
|--------|--------|
| 閾値未満 | 設定値内です |
| 閾値以上 | RestrictionMessage.txt |

---

## F06 結果表示

### 概要

利用時間およびメッセージを画面に表示する。

### 出力

- 利用時間
- メッセージ

# 5. データ設計

  "Applications": [

      "Name": "ChatGPT"
    },
    {
      "Name": "Copilot"
    }
  ]
}
```

### LearningMessage.txt

```

```text
利用時間が長くなっています。
一度休憩しましょう。
```

# 8. エラー処理

| No | 内容 | 対応 |
|----|------|------|
| 1 | 設定ファイルが存在しない | エラーメッセージ表示 |
| 2 | メッセージファイルが存在しない | 標準メッセージ表示 |
| 3 | イベントログ取得失敗 | エラーメッセージ表示 |
| 4 | 対象イベントが存在しない | 利用時間0として表示 |
